# Connected Vehicle Security（车联网安全）本地知识库

基于 [Delikely's Blog](https://delikely.eu.org/) 公开文章的主题与实践经验，整理为**便于浏览的本地知识库**，重点拆解：

- 车联网漏洞挖掘方法与攻击面
- 固件 / 协议栈 / OTA / 诊断安全测试要点
- 对应的防御与加固清单

## 如何使用

用浏览器打开：

```text
connected-vehicle-security/index.html
```

也可阅读：

| 文件 | 说明 |
|------|------|
| `index.html` | 主知识库（推荐） |
| `knowledge/black-gray-box.md` | 灰盒 / 黑盒攻击方式与逻辑细拆 |
| `knowledge/protocol-stack.md` | 车联网协议栈深入分析思路 |
| `knowledge/map.md` | 知识点 ↔ 原文链接映射 |
| `knowledge/checklist.md` | 挖洞 / 防御对照清单（Markdown） |

## 说明

- 内容为学习用**二次整合与摘要**，非原文全文转载。
- 细节与更新以作者博客为准：[https://delikely.eu.org/](https://delikely.eu.org/)
- 仅用于授权安全研究与合规测试。
