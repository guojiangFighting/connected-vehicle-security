# 挖洞 ↔ 防御 对照清单

## A. 硬件与调试接口

| 挖掘关注点 | 防御要点 |
|------------|----------|
| 串口 / JTAG / SWD / ADB / USB 调试未关 | 量产关闭或物理熔丝；调试口认证；壳内不可达 |
| SOP Flash 可夹取读出 | 加密存储 / 读保护；关键密钥不落明文 Flash |
| MCU 未开读保护 | 开启 RDP/PCROP；敏感算法放 HSM/安全区 |

## B. 系统与服务

| 挖掘关注点 | 防御要点 |
|------------|----------|
| Telnet/SSH 弱口令、默认口令 | 禁用明文远程管理；证书/密钥轮换；最小权限 |
| 全进程 root | 能力拆分、沙箱、SELinux/Smack |
| 过时组件（如已知 CVE 库） | SBOM + 补丁基线；OTA 可热修 |
| 私有服务明文传敏感数据 | TLS/私有加密；证书钉扎 |

## C. 固件与 OTA

| 挖掘关注点 | 防御要点 |
|------------|----------|
| 升级包明文/可截获 | 加密传输 + 完整性 |
| 签名校验可绕过 | 安全启动链；验签不可跳过 |
| 云端 OTA 平台漏洞 | 平台渗透与访问控制；最小暴露面 |
| 刷写无前置条件 | 车速/档位/电源等安全互锁 |

## D. UDS / 诊断刷写

| 挖掘关注点 | 防御要点 |
|------------|----------|
| Seed-Key 可预测 / 固定种子 | 真随机；会话绑定；失败锁定 |
| seed2key 库易逆向、常量硬编码 | HSM/安全存储；非对称（如 29 服务） |
| 34/36 无认证即可下载 | 强制安全访问；敏感 DID 保护 |
| CAN 上明文刷写可嗅探 | 加密下载标识；总线入侵检测 |

## D2. 协议栈 / 总线 / 服务通信

| 挖掘关注点 | 防御要点 |
|------------|----------|
| 无字典盲打；残留 DBC/ODX 未清 | 量产清理协议字典与密钥材料 |
| 网关域隔离可绕 / 盲信总线报文 | 关键信号认证或 MAC；严格转发策略 |
| DoIP 未激活即可诊断、跨域路由 | 路由激活与网络分段；最小诊断暴露 |
| SOME/IP / 私有 RPC 无鉴权 | 服务鉴权、证书、最小 Offer 面 |
| ISO-TP/UDS 状态机跳步 | 强制会话与安全访问顺序 |
| TBOX↔云私有协议可重放/伪造 | 抗重放、设备绑定、完整链路加密 |

## E. 无线与外设

| 挖掘关注点 | 防御要点 |
|------------|----------|
| 蜂窝降级 / GNSS 欺骗 | 抗降级策略；多源定位；异常检测 |
| Wi-Fi/BT 协议栈漏洞 | 补丁；关闭非必要配置模式 |
| USB 目录穿越 / 任意安装 | 路径规范化；签名应用；介质白名单 |

## F. 车机 / Android

| 挖掘关注点 | 防御要点 |
|------------|----------|
| ADB 未授权 | 量产关 ADB；授权令牌；网络安全配置 |
| 提权到 shell 后横移 ECU | 域隔离；网关防火墙；VLAN/域控策略 |

## G. 业务与合规

| 挖掘关注点 | 防御要点 |
|------------|----------|
| 跨境传输违规路径 | 数据分类；出境评估与监测 |
| 漏洞定级不清 | 参照 GB/T 等评级方法统一口径 |
